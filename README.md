Фреймворк: React 19 + TypeScript + Vite (быстрая сборка, мгновенный HMR).
Стилизация: Tailwind CSS v3/v4 + кастомный CSS-модуль эффектов Liquid Glass (зеркальные блики, преломление света, градиентные каймы, неоновые акценты).
Иконки: lucide-react (стилистика Apple SF Symbols).
Анимации: CSS Transitions / Tailwind Motion (плавный ход шторок, всплытие модальных окон, тактильный отклик кнопок).
API поиска: The Movie Database (TMDB v3 API) с готовым ключом по умолчанию + возможностью указать личный ключ в настройках + офлайн-каталог популярных фильмов на случай отсутствия сети.
Хранилище: localStorage с версионированием схемы и демонстрационными начальными данными (чтобы сразу видеть красивый интерфейс)

Юзать строго в целях личного использования, при нахождение автором данного приложения на просторах площадок с магическим образом вставленной рекламой, автор будет зол, а вы будете разбираться за неправомерное использование API TMDB.
